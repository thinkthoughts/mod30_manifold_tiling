\begin{abstract}
We study feature recovery on a controlled finite system defined by Mod30 residue classes. Using a continuous embedding of integers constrained to residues coprime with 30, we compare non-negative matrix factorization (NMF) and top-k sparse autoencoders (SAEs). We introduce metrics for structural recovery, redundancy, and capacity utilization. While NMF achieves higher coverage and efficient use of components, SAEs produce sparse and interpretable features but leave substantial latent capacity unused or redundant. These results show that sparsity-induced interpretability does not guarantee efficient representation, even with known ground truth.
\end{abstract}

\section{Introduction}

Understanding how models recover structure is difficult when ground truth is unknown. We construct a finite system where structure is explicit:

\begin{itemize}
\item integers mapped under modulo 30
\item filtered to residues coprime with 30
\item yielding 8 persistent residue classes
\end{itemize}

This provides a controlled testbed where:
[
\text{true features} = \text{residue lanes}
]

\section{Mod30 Residue Structure}

Let:
[
R = {1,7,11,13,17,19,23,29}
]

These define the persistent lanes. We embed filtered integers into a continuous space.

\section{Continuous Embedding}

Each integer is mapped to:
\begin{itemize}
\item circular coordinates
\item lane channels with local overlap
\item additive noise
\end{itemize}

\section{Models}

\subsection{NMF}

[
X \approx W H
]

Dense linear decomposition.

\subsection{Sparse Autoencoder}

[
X \rightarrow Z \rightarrow \text{top-k} \rightarrow \hat{X}
]

Only $k$ latent units active per sample.

\section{Metrics}

\begin{itemize}
\item Coverage: recovered lanes / total lanes
\item Purity: alignment with residue classes
\item Reconstruction error
\item Redundancy: activations per lane
\item Effective features: captured lanes / components
\item Dead / redundant feature fractions
\end{itemize}

\section{Main Result}

[
\text{sparsity} ;\Rightarrow; \text{interpretability} ;\text{but}; \text{inefficient capacity}
]

More precisely:

\begin{quote}
Dense factorization efficiently uses all components, while sparse autoencoders leave significant latent capacity unused or redundant even in overcomplete regimes.
\end{quote}

\section{Discussion}

Key tradeoff:
[
\text{efficiency} ;\leftrightarrow; \text{interpretability}
]

Sparse models:
\begin{itemize}
\item improve clarity
\item reduce completeness
\end{itemize}

\section{Conclusion}

We introduced a finite Mod30 system for evaluating feature recovery and showed:

\begin{itemize}
\item NMF recovers structure efficiently
\item SAEs produce interpretable but incomplete representations
\item sparsity does not guarantee effective utilization
\end{itemize}
