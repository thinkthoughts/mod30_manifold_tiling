\begin{abstract}
We study feature recovery on a controlled finite system defined by Mod30 residue classes.
Using a continuous embedding of integers constrained to residues coprime with 30, we compare
non-negative matrix factorization (NMF) and top-$k$ sparse autoencoders (SAEs). We introduce
metrics for structural recovery, redundancy, and capacity utilization. While NMF achieves higher
coverage and efficient use of components, SAEs produce sparse and interpretable features but leave
substantial latent capacity unused or redundant. These results show that sparsity-induced
interpretability does not guarantee efficient representation, even with known ground truth.
\end{abstract}

\section{Introduction}

This work responds to recent analysis of sparse feature recovery and manifold tiling in \cite{mod30_arxiv}, using Mod30 residue classes as a controlled finite analogue. Understanding how models recover structure is difficult when ground truth is unknown. We construct
a finite system where structure is explicit. 

This work is fully reproducible via an open notebook-based implementation \cite{mod30_repo}.

\begin{itemize}
    \item integers mapped under modulo 30,
    \item filtered to residues coprime with 30,
    \item yielding 8 persistent residue classes.
\end{itemize}

This provides a controlled testbed where
\[
    \text{true features} = \text{residue lanes}.
\]

\section{Mod30 Residue Structure}

Let
\[
    R = \{1,7,11,13,17,19,23,29\}.
\]

These define the persistent Mod30 lanes. We embed filtered integers into a continuous space and
evaluate whether factorization and sparse-learning methods recover these lanes.

\section{Models}

\subsection{Non-negative Matrix Factorization}

Non-negative matrix factorization (NMF) provides parts-based representations \cite{lee1999nmf}.

\[
    X \approx W H,
\]

where $W$ contains component activations and $H$ contains learned components.

\subsection{Sparse Autoencoder}

Sparse representations are commonly studied in overcomplete coding frameworks \cite{olshausen1997sparse}.

\[
    X \longrightarrow Z \longrightarrow \operatorname{top}\text{-}k(Z) \longrightarrow \widehat{X}.
\]

Only $k$ latent units remain active per sample after the top-$k$ mask.

\section{Metrics}

We evaluate both model families using the same recovery metrics:

\begin{itemize}
    \item \textbf{Coverage}: recovered lanes divided by total lanes.
    \item \textbf{Purity}: alignment of learned features with residue classes.
    \item \textbf{Reconstruction error}: relative error between $X$ and $\widehat{X}$.
    \item \textbf{Redundancy}: total activations divided by captured lanes.
    \item \textbf{Effective features}: captured lanes divided by total components.
    \item \textbf{Feature status}: dead, useful, and redundant feature fractions.
\end{itemize}

\section{Main Result}

\[
    \text{sparsity} \Longrightarrow \text{interpretability}
    \quad \text{but not necessarily} \quad
    \text{efficient capacity}.
\]

Dense factorization efficiently uses its components, while sparse autoencoders leave significant
latent capacity unused or redundant.
